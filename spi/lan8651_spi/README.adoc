= Attaching a LAN8651 10BASE-T1S Ethernet PHY via SPI

This example code demonstrates how to interface the Raspberry Pi Pico with a Microchip LAN8651 10BASE-T1S Ethernet PHY using SPI. The LAN8651 provides single-pair Ethernet (IEEE 802.3cg) connectivity and is managed through a specialized SPI interface.

The example includes:
- PHY initialization and reset sequences
- Register access via both direct and MMD (Clause-22) methods
- PHY identification and health monitoring
- MAC address reading

== Wiring information

Wiring up the LAN8651 requires the following connections:

   * GPIO  2 (pin  4) SCK/spi0_sclk  -> SCLK on LAN8651
   * GPIO  3 (pin  5) MOSI/spi0_tx   -> SDI  on LAN8651 (PHY input)
   * GPIO  4 (pin  6) MISO/spi0_rx   -> SDO  on LAN8651 (PHY output)
   * GPIO  5 (pin  7) Chip select    -> CS_N on LAN8651
   * GPIO  0 (pin 17) Reset control  -> RESET_N on LAN8651
   * 3.3v (pin 36)    -> VDDIO on LAN8651 (I/O power)
   * GND (pin 38)     -> GND on LAN8651

[NOTE]
======
The LAN8651 requires proper power supply configuration beyond just VDDIO. Ensure all power pins (VDD12, VDD33, etc.) are properly connected as specified in the datasheet. A typical evaluation board will handle this properly if you're using one.
======

== Key Features Demonstrated

- PHY hardware and software reset procedures
- Reading PHY identification registers (OUI, model, revision)
- Accessing OA (Operation and Administration) registers
- Reading the built-in MAC address
- Vendor-specific register access
- MMD (MDIO Manageable Device) register access
